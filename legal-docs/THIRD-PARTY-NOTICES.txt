2. REFERENCED BUT NOT DISTRIBUTED
--------------------------------------------------------------------------------

- html2canvas — NOT bundled in any tool.
  The pre-release audit of 21 August 2026 listed html2canvas as a missing
  notice. It was re-checked: the only occurrences of the name are inside jsPDF,
  which declares it as an optional peer dependency and tries to import it on
  demand for its `html()` rendering path. No html2canvas code and no
  html2canvas copyright banner is present in any published file, and the tools
  never take that code path. Nothing is distributed, so nothing is licensed
  here. If a future feature needs `jsPDF.html()`, the library will have to be
  vendored and this section updated (html2canvas is MIT, Niklas von Hertzen).

--------------------------------------------------------------------------------
3. LOADED FROM A THIRD-PARTY CDN AT RUNTIME
--------------------------------------------------------------------------------

- threejs-components 0.0.19 — MIT License
  https://github.com/vaalentin/threejs-components (upstream)
  Imported by the three homepages (/, /en/, /es/) as a dynamic ES module from
  https://cdn.jsdelivr.net/npm/threejs-components@0.0.19/... to animate the
  hero background. It is decorative: the import is wrapped in a timeout race
  and the page falls back to a static hero if it fails, so the site works
  without it.

  This is the only third-party network dependency on the whole site, and it is
  a supply-chain surface: a compromised CDN response would execute in the
  visitor's browser. It is pinned to an exact version, which prevents silent
  upgrades but not tampering with that version's bytes. Self-hosting the file
  under /assets/ — or adding a Subresource Integrity hash, which is not
  available for ES module imports and would require a classic script tag —
  remains open. The operational tools do not load it.

--------------------------------------------------------------------------------
4. FONTS AND ASSETS
--------------------------------------------------------------------------------

Web fonts are self-hosted under /assets/fonts/. No font, icon set, stylesheet
or script is fetched from a third party by the five tools.

--------------------------------------------------------------------------------
5. HOW TO KEEP THIS FILE HONEST
--------------------------------------------------------------------------------

This inventory was wrong before because nothing checked it: JSZip had been
vendored into two tools without being listed. When adding, removing or
upgrading a vendored library, update the table in section 1 in the same commit,
and grep the published HTML rather than trusting a package manifest — there
isn't one, the libraries are pasted into the files.
