Read the full prompt
Act as an accounting data-preparation assistant for Tax Automation Lab.

OBJECTIVE
Complete “Template_TaxTool_FS_AI.xlsx” so that it can be imported into the Italian statutory framework Reclassification tool without changing the required structure.

ATTACHED MATERIALS
I am attaching the template and one or more documents or exports containing the available company data. They may include, for example, a trial balance, chart of accounts, general-ledger extracts, management reporting, approved financial statements, a company-register extract or master-data sheets. This list is illustrative only: use any equivalent document that allows you to retrieve the required information.

PROCEDURE
1. Read the “Istruzioni” and “Voci IV Direttiva” sheets first.
2. Identify the company information and complete “Anagrafica”.
3. Enter one row for each balance-sheet account in “Stato Patrimoniale” and one row for each income or expense account in “Conto Economico”.
4. Report account code, description, current-year amount and, where available, prior-year amount.
5. Map each account only to a code listed in “Voci IV Direttiva”.
6. Record missing data, assumptions, sources and matters requiring professional review in “Esiti AI”.

MANDATORY RULES
- Do not rename or delete sheets, and do not add columns to the sheets imported by the tool.
- Do not invent data or classifications.
- Where a mapping is not sufficiently supported, leave “Voce IV Direttiva” blank and report the issue in “Esiti AI”.
- Preserve the source-file sign convention. Unless evidence indicates otherwise: assets and expenses positive; liabilities, equity and revenue negative; contra-asset provisions negative.
- Do not offset separate accounts or aggregate rows unless the source itself is already aggregated.
- Enter values only, with no formulas or external links.

EXPECTED RESULT
Return the completed XLSX file with the exact sheet names and headers, together with a very brief summary of completed data and outstanding reviews. A professional will review the file before import.

MANDATORY RULE — ACCOUNTS, SUBACCOUNTS AND GRANULARITY
- Never merge a subaccount into its parent account. Preserve every source accounting row independently.
- Keep the complete ERP account code unchanged; do not invent suffixes or renumber accounts.
- Preserve repeated account codes with different descriptions as separate rows.
- The output row count must equal the source accounting-row count, excluding only blank and clearly identified total rows.
- Reconcile row counts before returning the file and disclose every exclusion.

The prompt tells the AI not to invent information, not to change the template structure and to separate all review points clearly.

Read the full prompt
Act as a VAT data-preparation assistant for Tax Automation Lab.

OBJECTIVE
Complete “LIPE_Codiciario_AI.xlsx” to configure the client’s master data and permanent VAT-code mapping once in the LIPE Generator.

IMPORTANT
This file is only for client setup. Do not enter monthly or quarterly amounts. Period amounts will be uploaded later directly in the tool.

ATTACHED MATERIALS
I am attaching the template and one or more documents or exports that explain the VAT codes. They may include, for example, an ERP VAT-code list, VAT ledgers, periodic VAT calculations, accounting reports, posting examples, previous LIPE filings or XML files, or internal instructions. This list is illustrative only: use any equivalent document that reliably explains the codes and master data.

PROCEDURE
1. Read “Istruzioni”, “Anagrafica” and “Codiciario” first.
2. Complete master data using only information supported by the documents.
3. Enter every permanent VAT code in “Codiciario”, with a clear description.
4. Set VP destinations only where supported:
   - “Imponibile →” = VP2 for output transactions or VP3 for input transactions;
   - “IVA esigibile →” = VP4;
   - “IVA detraibile →” = VP5;
   - a reverse-charge code may flow to VP3, VP4 and VP5 at the same time where the documents support this;
   - an excluded code must have all destinations blank, with the reason stated in Notes.
5. Use percentages only for partial allocation; otherwise leave them blank so that the tool applies 100%.
6. Record ambiguous codes, missing data, assumptions and sources in “Esiti AI”.

MANDATORY RULES
- Do not rename sheets or headers and do not add columns to “Codiciario”.
- Do not invent VAT treatments.
- If a destination is not sufficiently supported, leave it blank and report the issue in “Esiti AI”.
- Do not infer the VAT treatment from the code number or abbreviation alone.
- Do not enter period taxable amounts or VAT amounts in this file.
- Enter values only, with no formulas or external links.

EXPECTED RESULT
Return the completed XLSX file and a very brief summary of configured codes, excluded codes and matters requiring professional review. A professional will review the file before import.

The prompt tells the AI not to invent information, not to change the template structure and to separate all review points clearly.

TAX FOR AUDIT · COMPLETE FILE

TFA Client File

Prepare client data, Analytical records and initial Commentary drafts in one workbook. A protected preview is shown before import, unsaved work is guarded and both views are populated without losing unclassified information.

Useful materials, including equivalent sources

  • Company extract, organisation chart and corporate information
  • Financial statements, trial balance and tax computation
  • Tax returns, payments and tax-asset schedules
  • Working papers, reports, contracts, disputes or IRL
Relevant information that cannot be classified reliably is preserved in “Other”, with its source, relevance and reason for non-classification. After import, the tool clearly distinguishes the local draft from the archived file and can back up the complete client archive.
Download template ↓Open tool (IT) →
Read the full prompt
Act as a tax data-preparation assistant for Tax Automation Lab.

OBJECTIVE
Complete “TFA_Client_File_AI.xlsx” to prepare an initial TFA Client File configuration. The workbook must populate at the same time:
- client master data and common file information;
- Analytical mode, with structured records;
- Commentary mode, with initial narrative drafts;
- the “Other” section, for relevant information that cannot be classified reliably.

AVAILABLE MATERIALS
I am attaching the template and one or more documents, reports or exports. They may include company extracts, organisation charts, financial statements, trial balances, tax computations, tax returns, payment forms, working papers, tax reports, contracts, disputes, tax-asset schedules, Information Request Lists (IRLs) or equivalent documents. The list is illustrative only: use any attached source that supports the requested information reliably.

OPERATING INSTRUCTIONS
1. Read the “Istruzioni” sheet in full before completing the workbook.
2. Do not rename the sheets “Istruzioni”, “Anagrafica”, “Analitica” and “Commentary”.
3. Do not change headers, field codes or table structures.
4. In “Anagrafica”, fill only the “Valore” column and record the source and status whenever available.
5. Enter the tax year as four digits between 2000 and 2100, for example 2026; do not use labels such as “FY2026”.
6. Use recognisable numeric values for amounts and thresholds. Italian (1.234,56) and international (1,234.56) formats are accepted. Do not mix text or currency symbols into numeric cells.
7. In “Analitica”, use the predefined sections and field codes. For multiple items of the same type, duplicate the relevant row group and assign unique record IDs such as CT-001 and CT-002.
8. For the Information Request List (IRL), complete the requested document, area, status, owner, deadline, comment and impact on the work whenever available.
9. In “Commentary”, draft clear, technical and concise text, distinguishing documented facts, inferences, limitations and items still requiring verification.
10. If relevant information cannot be classified reliably, DO NOT force it into the wrong section. Put it in “miscItems” / “Other” in “Analitica”, using ALT-001, ALT-002 and so on, and complete title, information, source, relevance, status and reason for non-classification.
11. If a code or section does not apply, leave the value blank or mark the status as “Not applicable”; do not invent data.
12. Mark inferred information as “Inferred” and explain the assumption in the notes.
13. Do not make unsupported tax, legal or audit conclusions.

FINAL CHECKS
- Check that company name and tax year are consistent throughout the workbook.
- Check that every Analytical record has a unique ID.
- Make sources, assumptions and items requiring confirmation explicit.
- Preserve every relevant item; use “Other” when classification is not reliable.
- Do not change the XLSX template format.

OUTPUT
Return the completed XLSX with exactly the same structure, sheets and headers. Add a short summary of:
- completed data;
- records created by section;
- information placed in “Other”;
- assumptions and professional checks still required.

The professional will review the preview before import, choose whether to create or update the file and explicitly save it to the archive. Complete archive backup remains a separate tool action.

The prompt populates Analytical and Commentary views, preserves sources and review status, uses “Other” for unclassified information and produces a workbook compatible with the TFA protected preview.

UPLOAD INSTRUCTIONS

Where do I upload the import files?

Completed templates are uploaded directly into the operational sections of each tool. The screens below show the exact route. The operational interfaces remain in Italian.

01 · FINANCIAL STATEMENT

Financial Statement

Financial Statement → left menu “2 Import bilancio” → section “2. Carica il file compilato” → “Carica Excel compilato” or drag and drop.
02 · LIPE — SETUP

LIPE VAT-code mapping

LIPE Generator → “Gestione clienti” → “Codiciario IVA” panel → “Importa Excel codiciario”. Review the mapping and then save the client configuration.
03 · LIPE — PERIOD

What about LIPE period amounts?

LIPE Generator → “Elaborazione periodica” → select client, year and quarter → “Carica Excel importi”. This file contains the period figures and remains separate from the permanent mapping.
04 · TFA CLIENT FILE

TFA Client File

TFA Client File → top command bar → “Import Excel” → review the preview → choose “New file” or “Update current” → review Analytical, Commentary and Other → “Save to archive”. To secure all client files use Actions → “Export complete archive”.
