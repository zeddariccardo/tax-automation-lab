# Tax Automation Lab

Source files for the public website **taxautomationlab.com**.

The four professional tools are available exclusively through the website and process data locally in the user’s browser. No standalone tool package or guide is distributed through this repository or through GitHub Releases.

Before professional use, always verify data, rules and generated results. Local browser archives may be lost when changing device or clearing site data; export backups regularly.
