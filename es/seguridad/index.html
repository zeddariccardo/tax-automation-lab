Política de seguridad

Seguridad

Cómo funcionan las herramientas, cómo informar de problemas y qué limitaciones deben considerarse.

Última actualización: 24 de julio de 2026

Procesamiento local

Las herramientas están diseñadas para procesar los archivos en el navegador. No requieren cuenta, autenticación ni instalación de software y no envían los documentos cargados a una base de datos del sitio.

Comunicación de problemas

Para informar de una vulnerabilidad o comportamiento inesperado, escribe a security@taxautomationlab.com. Incluye una descripción, los pasos para reproducir el problema y el impacto observado. No envíes datos personales ni documentos confidenciales.

Limitaciones

Ningún sistema puede describirse como exento de riesgo. Las herramientas deben utilizarse con navegadores actualizados y archivos procedentes de fuentes fiables. Los resultados deben someterse a revisión profesional. Las bibliotecas incorporadas y sus versiones se detallan en los avisos de terceros.
