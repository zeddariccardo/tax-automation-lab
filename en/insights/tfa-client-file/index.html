How to build a reusable and verifiable annual tax file

Published and updated on 25 July 2026

From the permanent client profile to the annual file: documents, tax calculation, tax returns, open points, conclusions and controlled roll-forward.

Tool available · Client tax file v1.7.0

Separate permanent and annual data

An effective tax file distinguishes information that describes the client permanently — identity, group, regimes, options and controls — from information belonging to a specific year. This avoids rebuilding the same context every year and makes required updates explicit.

Centralised Information Request List

Requested documentation should not live across emails, notes and separate files. A centralised IRL links each document to area, status, owner, deadline, comment and impact on the work. File completion becomes measurable and reviewable.

Tax calculation and tax returns

The working paper should connect materiality, business changes, extraordinary transactions, tax assets, deferred tax, transfer pricing, tax returns and reconciliations. Missing elements remain visible as findings or open requests.

Open points and conclusions

An open point is more than a note. It should state the area, description, status, impact, response received, any adjustment and the conclusion. Commentary mode summarises the work; Analytical mode retains the detail.

Client archive and annual roll-forward

Roll-forward to the new year must be controlled: permanent data and configurations may be carried forward, while prior-year amounts, outcomes and conclusions must not be copied automatically without an explicit decision.

Data resilience and guided workflow

The file is stored locally in the browser. The tool therefore keeps the draft and the archived file visibly distinct and never reports a successful save when the browser has rejected it.

Actions that can overwrite work require confirmation. A stable client identifier keeps annual files together even when tax identifiers are corrected.

  • Permanent status badge: not archived, changes to archive or archived file.
  • Complete archive export and restore with conflict handling.
  • Global search, starter checklist and one command bar.
  • Tax-year and amount validation before applying an Excel import.

Outputs, limitations and responsibility

The tool produces Excel, PDF, JSON and HTML reports and stores data locally in the browser. It does not replace audit procedures, professional judgement or validation of tax conclusions.

AI-assisted onboarding and Excel import

The TFA template can transform company documents, tax computations, returns, reports and working papers into an initial tax-file configuration. The import populates company data, Analytical mode and Commentary mode at the same time; before confirmation, the tool presents a summary of recognised data and items requiring review.

  • The workbook keeps permanent data, analytical records and narrative drafts separate.
  • The user chooses whether to create a new file or update the current one.
  • Saving to the archive remains an explicit action after import.

The “Other” section prevents forced classification

When information is relevant but cannot be assigned reliably to a standard section, the AI must preserve it in “Other”, recording the source, relevance, review status and reason why it could not be classified. The information is not lost and remains available for professional assessment.
