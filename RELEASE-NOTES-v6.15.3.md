# Release v6.15.3

## Analisi di bilancio v2.0.3

- Corretto il pulsante Dashboard mancante nella sidebar sinistra.
- La voce Dashboard viene ora inserita direttamente prima di Riclassificazioni.
- La voce resta disponibile dopo ogni ricostruzione dinamica della sidebar.
- Aggiunta una protezione con MutationObserver contro successive rimozioni del pulsante.
- Il click apre sempre la vista Executive Dashboard e ne aggiorna il contenuto.

Questa release è correttiva e mantiene tutte le funzionalità della v6.15.2.
